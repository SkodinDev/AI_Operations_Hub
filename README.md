# AI Operations Hub

A full-stack AI-powered customer support operations dashboard built with Python, FastAPI, PostgreSQL, JavaScript, HTML, CSS, and DeepSeek AI.

## Features

- Create customer support tickets
- View all tickets
- Update ticket information
- Delete tickets
- Change ticket status
- Dashboard statistics
- AI customer support assistant
- AI-powered ticket summaries
- AI-generated suggested support responses
- PostgreSQL database integration
- REST API backend

## Technologies Used

- Python
- FastAPI
- PostgreSQL
- JavaScript
- HTML
- CSS
- DeepSeek AI
- Git & GitHub
